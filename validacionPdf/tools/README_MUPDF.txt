========================================================================
CARPETA DE HERRAMIENTAS PORTABLES: MUPDF (mutool.exe)
========================================================================

Para activar el motor de velocidad extrema MuPDF (30 a 50 páginas por segundo):

1. Descarga el paquete oficial de MuPDF para Windows desde:
   https://mupdf.com/releases/ o https://github.com/ArtifexSoftware/mupdf/releases

2. Extrae el archivo "mutool.exe" (versión de 64 bits).

3. Coloca el archivo "mutool.exe" directamente en esta carpeta:
   {RutaDelPrograma}\tools\mutool.exe

La aplicación detectará automáticamente MuPDF al iniciar y lo utilizará como
motor preferente de máxima velocidad, con compresión multihilo y eliminación
inmediata de imágenes temporales para proteger el almacenamiento de disco.
========================================================================
